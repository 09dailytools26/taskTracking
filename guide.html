1公開する（最初の1回だけ・パソコンで）

宿題手帳と同じように、GitHub Pagesで公開します。宿題手帳とは別のリポジトリを作ってください。

  1. study-planner.zip を展開します。中に index.html、guide.html、guide-en.html、sw.js、manifest.webmanifest、アイコン画像3つの、合わせて8つのファイルがあります。
  2. GitHubの右上の ＋ →「New repository」で、名前を study-planner、Public にして作ります。
  3. 水色の枠の中の「uploading an existing file」を押し、8つのファイルをまとめてドラッグして、下の「Commit changes」を押します。フォルダごとではなく、フォルダの中のファイルをドラッグします。
  4. 「Settings」→「Pages」で、Branch を main、フォルダを / (root) にして「Save」を押します。
  5. 数分後、Pagesの画面に https://ユーザー名.github.io/study-planner/ と出ます。このアドレスを娘さんに送ります。
公開されるのは空のアプリだけです。教科、課題、勉強時間などの記録は、使う人のiPhoneの中だけに保存されます。

2iPhoneのホーム画面に入れる

  1. 送られてきたアドレスを Safari で開きます。
  2. 共有ボタン →「ホーム画面に追加」を選びます。「Webアプリとして開く」があればオンにします。
  3. 「追加」を押すと、ホーム画面に「Study」のアイコンができます。
  4. Safariを閉じて、アイコンから開きます。
Safariの画面のまま使い始めないでね。
Safariとホーム画面のアイコンでは、記録が別々に保存されます。

最初の画面で言語（日本語 / English）を選べます。あとから設定でも変えられます。「例を入れてはじめる」「空の状態ではじめる」も選べます。例を入れると、使い方のイメージがつかみやすいです。例には「（例）」と付いているので、あとで消したり書き換えたりしてください。

3教科と色を決める

  1. 下のタブの 設定 →「教科と色」を開きます。
  2. ＋ 教科を追加 で教科名を入れ、12色のパステルカラーから色を選びます。「好きな色を選ぶ」を押すと、好きな色を自由に選べます。
  3. 登録した教科を押すと、名前や色を変えたり、削除したりできます。

4毎週の課題を登録する

英単語や課題プリントなど、毎週くり返す課題を登録します。設定 →「毎週の課題」→ ＋ 毎週の課題を追加 から追加します。

曜日を決める「する日を選択」で曜日を選びます（毎日なら全部選択）。その曜日の「今日すること」に出ます。
期限を決める曜日は決めずに「毎週○曜日までに」終わらせる課題です。週の初めから「今週中にすること」に出て、完了するとその週は出なくなります。
テスト期間は休みにするオンにすると、テストの数日前からテスト最終日まで表示されません。テスト勉強に集中したい課題に使います。何日前からにするかは設定の「テスト期間」で変えられます。

5今日の画面

一番上次のテストまでの残り日数です。押すとそのテストの画面に移ります。
勉強時間今日の勉強時間の合計と、教科ごとの時間です。
今日すること「毎日の課題」「今週中にすること」「期限が近いもの（1週間以内）」に分かれて並びます。丸を押すと完了です。
完了したもの今日終わったものの一覧です。間違えたときは「戻す」を押します。

右の ⋯ から「今日は休みにする」（毎週の課題）や、編集・削除（期限つきの課題）ができます。上の ‹ › で前後の日も見られます。

6提出物・期限つきの課題

「10月3日までにレポート提出」のように、日付で期限が決まっている課題です。今日の画面か 予定 の ＋ 課題を追加 から登録します。

  1. 教科を選び、内容と期限（日付）を入れます。
  2. 期限の1週間前から「今日すること」に出ます。すべての課題は 予定 の「提出物・課題」で見られます。
  3. 期限の前日は「明日まで」、当日は「今日まで」、過ぎると「期限切れ」と表示されます。

7テストと勉強計画

テストを登録する

  1. 予定 → ＋ テストを追加 を押します。
  2. テスト名、初日、最終日を入れます。
  3. 教科ごとに試験日と範囲（教科書やワークのページなど）を入れます。範囲が分かっている教科だけで大丈夫です。

勉強計画を立てる

テストの画面では、教科ごとに範囲と勉強計画が並びます。＋ 勉強計画を追加 で「ワーク p.20〜35」のような課題を期限つきで追加します。期限は、はじめはその教科の試験日の前日になっています。計画の課題も、期限が近づくと「今日すること」に出ます。

テストの画面の上には、残り日数と計画の進み具合が表示されます。範囲が変わったときは右上の「編集」から直せます。

8勉強時間を記録する

タイマーで今日の画面の ▶ はじめる を押して教科を選ぶと、時間を計り始めます。終わったら おわり を押すと記録されます。アプリを閉じても計り続けます。
あとから入れる＋ 記録 を押し、教科と時間（分）を入れます。「30分」「1時間」などのボタンを押すと足されていきます。日付を変えれば、前の日の分も入れられます。

9記録の画面

記録 では、1週間の勉強時間を曜日ごとのグラフで見られます。グラフの棒を押すと、その日の教科ごとの時間が出ます。その下に教科ごとの合計時間と、毎日の課題をどれだけ完了できたかが表示されます。‹ › で前の週も見られます。

10バックアップと機種変更

記録はiPhoneの中だけにあるので、ときどきバックアップしておくと安心です。前回から2週間たつと、今日の画面にお知らせが出ます。

  1. 設定 → バックアップを保存 →「"ファイル"に保存」でiCloud Driveなどに保存します。
  2. 新しいiPhoneでは、ホーム画面に追加したあと 復元する で保存したファイルを選びます。
復元すると、そのiPhoneの今の記録はバックアップの内容に置き換わります。

11よくある質問

過去の記録は消えますか？
アプリが自動で消すことはありません。ただ、ホーム画面のアイコンを削除したときや、iPhoneの設定でSafariの「履歴とWebサイトデータを消去」をしたときは消えることがあります。バックアップがあれば戻せます。
電波がなくても使えますか？
一度アイコンから開いたあとは、電波がなくても使えます。
アドレスを知られたら、記録を見られますか？
見られません。記録は自分のiPhoneの中だけにあります。
アプリが新しくなったら？
GitHubの study-planner リポジトリに新しいファイルをアップロードすると更新されます。記録はそのまま残ります。新しい版は、アプリを閉じて開き直すと表示されます。
